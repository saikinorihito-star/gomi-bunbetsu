# ごみ分別辞典（iPhone向けWebアプリ）

無料・アカウント不要の、自治体ごとのごみ分別ルールを検索するアプリです。HTML/CSS/JavaScriptだけで動作します。サーバーや有料APIは不要です。

## できること
- 「モバイルバッテリー」「スプレー缶」など品目名から検索
- 分別区分、出し方・注意事項、回収不可品目を表示
- 自治体の公式資料へのリンクを表示
- 自治体の追加と切替
- 公式資料のPDF（高岡市の4列形式）、CSV、TSV、JSONから品目を取り込み
- お気に入り、バックアップと復元
- 高岡市については、2026年9月から始まった小型充電式電池の拠点回収情報と、スプレー缶の火災防止案内を優先表示

## 短い「アルミ」識別表示への対応（2026年11月）
- 「アルミ缶」「アルミ製」だけでなく、リサイクルマークに単独で書かれた「アルミ」も読み取って候補にします。
- 最初の日本語OCRで明確な材質表示が見つからない場合は、元写真の中央のラベル領域を拡大して再認識します。これでも読み取れない場合は「アルミ」の手動選択が利用可能です。
- 「アルミ」は材質表示であり、それだけで飲食用缶かは確定しません。飲食用缶であることを確認した場合、高岡市の「飲食用缶類（スチール缶・アルミ缶）」と、地区の収集日を表示します。
- スプレー缶・充電式電池の注意表示は優先扱いとし、危険物を飲食用缶類に誤分類しないようにしています。
- OCRは端末内処理ですが、実際のiPhoneでこの写真を正しくOCRできるかは未検証です。文字判定・分類・画面の自動テストで回帰を確認します。

## 写真の分別結果を最初に表示（2026年11月更新）
- OCR結果の下に、分別区分・具体的な出し方・収集日の要点を先に表示します。似ている物体の一覧とOCR詳細は折りたたみ式にしています。
- ラベルに「プラ」があると確認した高岡市の対象容器は、「プラスチック資源類」と表示します。「ボトル」という文字のみでは、飲食用PETボトルと推測しません。OCRがプラマークを読み取れない場合、本人が実物を確認するボタンを表示します。
- 高岡市の地区（校下）を一度選択すると、2026年4月〜2027年3月の高岡市公式収集カレンダーから次の「燃やせないごみ」収集日を表示します。地区未登録・2027年4月以降は日付を推測しません。
- 地区名と正式な町名が対応しない場合や、同じ町名でも例外がある場合は市の公式住所別検索で確認してください。収集日当日は朝8:30までが指定されています。
- 現在の地区設定はブラウザ内の別キーに保存されます。登録した自治体が高岡市以外の場合、分別区分・収集日を推測しません。
- 根拠：[高岡市プラスチック一括回収](https://www.city.takaoka.toyama.jp/gyosei/kurashi_tetsuzuki/gomi_recycle/2/5710.html)、[収集カレンダー2026年度](https://www.city.takaoka.toyama.jp/soshiki/kankyoseisakuka/2/1/4/1/1/4860.html)、[高岡市の地区別収集日検索](https://www.city.takaoka.toyama.jp/soshiki/kankyoseisakuka/2/1/4/3/2/10496.html)、[プラスチックを出す袋](https://www.city.takaoka.toyama.jp/soshiki/kankyoseisakuka/2/1/4/2/2704.html)。

## ラベル・識別表示を読み取る（2026年11月追加）
- 写真を選択すると日本語・英語OCR（Tesseract.js v5.1.1）が先に走り、ラベル文字から「プラ」「PET」「紙」「アルミ」「スチール」、スプレー・電池関連の注意表示を候補として提示します。
- 取得した文字と、識別表示を推測した根拠を表示します。「プラ」「PET」などのマークは読めないことがあるため、利用者が写真を見て選び直すボタンも用意しています。
- OCRのあとに既存の外観AIを補助として動かします。両方の判別結果は確定情報ではなく、自治体の登録済み品目への候補リンクです。合致しない品目は勝手に分別区分を確定しません。
- 「プラ」マークは容器包装の識別表示であり、自治体がリサイクル回収することの証明ではありません。中身、汚れ、用途、電池の有無などは本人が確認してください。
- OCRライブラリと言語モデルは初回にCDNから取得します。OCR画像は端末内で処理され、外部の画像認識APIには送信しません。iPhone Safari実機のOCR精度は未検証です。

## 写真から品目の候補を探す（追加機能）
1. ホーム画面の「📷 写真から品目を調べる」を押します。
2. 「カメラで撮影」または「写真を選ぶ」を押し、品目を1点だけ写した写真を使います。
3. 初回は画像認識ライブラリと小型AIモデルをダウンロードします（概ね数十MB、Wi-Fi推奨）。端末・回線によっては失敗する可能性があります。
4. AIが提案した候補の**正しい品目を自分で選択**すると、登録した自治体の公式分別ルールが開きます。辞典未登録の品目は文字検索へ進めます。

**写真の取扱い**：写真はiPhoneのブラウザ内で縮小して判別に使い、画像解析APIや外部サーバーにはアップロードしません。AIのモデルファイルだけをネットから取得します。撮影した写真はアプリの永続保存データには含まれません。モデル配布先・CDNには接続します。

**精度・制約**：候補の写真分類は機械学習による推定であり、必ず正しく判別されるわけではありません。写真から材質（プラと金属の混合等）、電池の内蔵、スプレー缶の残量、膨張・破損、汚れなどは確定できません。**候補を選び、公式資料で分別ルールを最終確認してください。** 候補は現在対応している基本的な品目群に限られます。特に端末内AIはiPhoneのメモリー・回線状況に依存し、実機での画像判定精度は未検証です。モデルを読み込めない場合でも文字検索は利用できます。

## iPhoneで使う最短手順
1. ZIPを解凍し、`gomi-bunbetsu-app` 内のファイルをGitHubの新しいリポジトリの**ルート**にアップロードします。フォルダーごとアップロードして一段深くしないでください。
2. GitHubの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選び、Branchを `main`、Folderを `/ (root)` にしてSaveします。
3. 表示された `https://ユーザー名.github.io/リポジトリ名/` にiPhone Safariでアクセスします。
4. Safariの共有メニュー → **ホーム画面に追加** でアプリとして利用できます。

## 高岡市公式PDFの取り込み方法
1. アプリの「資料・設定」→「公式資料を取り込む」を開きます。
2. 「公式分別資料を開き...」から高岡市のPDF（72ページ）をiPhoneの「ファイル」に保存します。
3. アプリに戻り、**PDF ファイルを選択**します。
4. 自動抽出された件数・内容を確認し、誤りがなければ「登録」を押します。
5. PDF解析ライブラリは初回にインターネットから取得します。PDFの内容自体はiPhone内で処理され、外部サーバーにはアップロードしません。

**重要**：PDF解析は4列表（索引／ごみ名／分別区分／備考）を想定しています。市町村によってPDFの表構造が異なるため、他市町村のPDFが必ず解析できるわけではありません。抽出結果の検証は必須です。CSV・TSV・JSONは市町村を問わず使えます。CSV見本はアプリから取得可能です。

## 情報の扱い
- 標準の内蔵データは、**2024年10月の高岡市公式一覧表に由来する確認済みのサンプル品目のみ**です。内蔵だけでは一覧表の全品目はありません。
- 高岡市の小型充電式電池は2026年9月の公式案内を新しい情報として優先します。PDFが古い場合でも当該4品目は新情報を表示します。
- 自動で自治体の更新を確認する仕組みはありません。新しい資料が出たら再インポートしてください。
- 分別情報は家庭ごみ向けです。事業系ごみは対象外です。
- スプレー缶の穴開けなど危険を伴う作業は、実施前に必ず**自治体の最新の公式案内**を確認してください。自治体によってルールが違います。
- アプリ自体は自治体の公式サービスではありません。

## ファイル構成
- `index.html`：画面
- `styles.css`：デザイン
- `seed-data.js`：確認済みの品目と高岡市の新しい案内
- `app.js`：検索・保存・資料取込機能
- `photo-ai.js`：写真撮影・判別候補の表示・自治体データ照合
- `photo-worker.js`：端末内AIによる画像判別（初回はオンラインでモデル取得）
- `manifest.webmanifest`, `icon.svg`, `sw.js`：ホーム画面とオフライン表示

## セキュリティ・保存
- データは端末のブラウザのlocalStorageに保存します。ユーザーのアカウントや外部連携はありません。
- 同じGitHub Pages URLでアプリを更新した場合、通常は保存データが維持されますが、Safari側でサイトデータを削除したりURLを変更すると失われる場合があります。「資料・設定」→「データをバックアップ」を推奨します。
- 解析ライブラリはCDNから読み込むため、PDF取り込みにはインターネット接続が必要です。検索は、データが保存されていればオフラインでも使用できます。
